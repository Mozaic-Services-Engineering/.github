# Mozaic Engineering Defaults

This repo provides shared community health files and engineering operating-model defaults for `Mozaic-Services-Engineering`.

Key documents:

- `ENGINEERING-OPERATING-MODEL.md`
- `ISSUE-HIERARCHY.md` (retired; points to the canonical operating model)
- `LABEL-TAXONOMY.md`
- `CONTRIBUTING.md`
- `.github/ISSUE_TEMPLATE/`: one issue template per Issue Type (Epic, Feature,
  Story, Task, Bug, Spike) that sets the Type and the §10 headings

Issue location, linking and format rules live in the
[GitHub Issue and Project Operating Model](https://github.com/Mozaic-Services-Engineering/mozaic-platform-docs/blob/main/docs/engineering/operating-model/consultancy-on-tap/github-issue-and-project-operating-model.md).
